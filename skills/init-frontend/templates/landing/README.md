# Landing Template

This is a base landing page template initialized with init-frontend principles.

## Design Principles (anti-AI-slop)

- No Inter by default — uses system font stack
- No purple/blue gradients
- No hero+3-cards boilerplate
- No glassmorphism
- Touch targets ≥ 24px
- Focus-visible rings preserved
- Words first, constraints before options

## Structure

- `src/pages/index.html` — landing page
- `src/components/` — component library
- `src/tokens/` — design tokens
- `src/styles/base.css` — responsive base styles

# Templates

Available template categories for `ufmw init-frontend template <category>`:

- **landing** — Marketing landing page
- **portfolio** — Personal portfolio
- **blog** — Content blog
- **ecommerce** — Online store
- **dashboard** — Data dashboard
- **admin** — Admin interface
- **saas** — SaaS application
- **docs** — Documentation site
- **restaurant** — Restaurant site
- **realestate** — Real estate listing
- **event** — Event page
- **nonprofit** — Nonprofit organization
- **resume** — Personal resume/CV

Plus `examples/` — 12 example reference sites.

All templates follow init-frontend principles:
- No Inter by default
- No purple/blue gradients
- No hero+3-cards boilerplate
- No glassmorphism
- Touch targets ≥ 24px
- Focus-visible rings preserved
- WCAG 2.2 AA accessible
- Performance budgets enforced

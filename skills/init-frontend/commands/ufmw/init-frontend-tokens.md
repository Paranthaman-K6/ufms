# ufmw init-frontend tokens

Initialize the design-token tier with a Style Dictionary build pipeline.

Usage:
  ufmw init-frontend tokens

Output:
  - tokens/ — design tokens (color, typography, spacing, etc.)
  - style-dictionary.config.js — build configuration
  - .ufme/DESIGN_SYSTEM.md — updated with token definitions

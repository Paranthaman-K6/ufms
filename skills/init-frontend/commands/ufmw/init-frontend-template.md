# ufmw init-frontend template

Download a template by category and re-apply init-frontend design-system principles.

Usage:
  ufmw init-frontend template <category>

Arguments:
  category  Template category: landing, portfolio, blog, ecommerce, dashboard, admin, saas, docs, restaurant, realestate, event, nonprofit, resume

Output:
  - Templates applied to current project directory
  - .ufme/REFERENCES.md — template source recorded

# 06 — Implementation

## Goal
Build pages, reusable components, navigation, forms, state, loading/error/empty states,
responsive layouts, animations, and PWA readiness where justified.

## Steps
1. Read `.ufme/ARCHITECTURE.md`, `.ufme/DESIGN_SYSTEM.md`, `.ufme/TASKS.md` (approved
   feature slice).
2. Implement the next approved feature slice preserving existing architecture.
3. Include loading, error, and empty states on every data-dependent view.
4. Implement responsive layouts at mobile/tablet/laptop/desktop breakpoints.
5. Implement the motion hierarchy from `.ufme/DESIGN_SYSTEM.md` — not one shared entrance
   variant on every section. No control without behaviour; no permanent scrim hiding the
   primary work; verify the declared grid actually lays out.
6. Update `.ufme/TASKS.md` via the orchestrator.
7. Delegate next: integration (if backend) or browser execution.

## Output
- Frontend source files (pages, components, layouts, forms)
- `.ufme/TASKS.md` updated

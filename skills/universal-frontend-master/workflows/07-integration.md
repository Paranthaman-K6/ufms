# 07 — Integration

## Goal
Connect the frontend to confirmed backend endpoints.

## Steps
1. Read `.ufme/API_MAP.md`, `.ufme/AUTHENTICATION_MAP.md`, `.ufme/ERROR_HANDLING.md`,
   `.ufme/BACKEND_CAPABILITIES.md`.
2. Implement typed API client using only confirmed endpoints.
3. Implement authentication flows, authorization-aware UI, validation, error handling,
   retries where appropriate, network failure states.
4. Do not call endpoints absent from `.ufme/API_MAP.md`.
5. Update `.ufme/TASKS.md` via the orchestrator.
6. Delegate next: browser execution.

## Output
- Typed API client
- Auth flows, authorization-aware UI, validation, error handling, retries, network failure states

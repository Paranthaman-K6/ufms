# Backend Capabilities

| Capability | Evidence source | Status | Frontend feature | Rationale |
|------------|----------------|--------|------------------|-----------|
|            |                | CONFIRMED / INFERRED / MISSING_BACKEND / NOT_APPLICABLE / DO_NOT_BUILD |  |  |

Status scale:
- CONFIRMED: verified in code or specification.
- INFERRED: strongly suggested but not directly evidenced.
- MISSING_BACKEND: backend does not provide it.
- NOT_APPLICABLE: not relevant to this frontend.
- DO_NOT_BUILD: deliberately not exposed to the frontend.

# 04 — Product Intelligence

## Goal
Create PRD, sitemap, user flows, feature matrix, user roles, and acceptance criteria. Map
every confirmed backend capability to a frontend feature or document why it is absent.

## Steps
1. Read `.ufme/PROJECT_SPEC.md`, `.ufme/API_MAP.md`, `.ufme/BACKEND_CAPABILITIES.md`.
2. Create `.ufme/PRD.md` (goals, user roles, acceptance criteria).
3. Create `.ufme/SITEMAP.md` (page hierarchy and routes).
4. Create `.ufme/USER_FLOWS.md` (key user journeys).
5. Create `.ufme/FEATURES.md` (feature matrix mapped to confirmed backend capabilities;
   document why any capability is absent).
6. Update `.ufme/TASKS.md` (T-05) and `.ufme/AGENT_STATE.md`.
7. Delegate next: design.

## Output
- `.ufme/PRD.md`
- `.ufme/SITEMAP.md`
- `.ufme/USER_FLOWS.md`
- `.ufme/FEATURES.md`

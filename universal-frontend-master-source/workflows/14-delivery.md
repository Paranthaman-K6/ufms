# 14 — Delivery

## Goal
Hand off the complete, tested, production-ready website.

## Steps
1. Confirm all acceptance criteria in `.ufme/PRD.md` pass, or limitations documented in
   `.ufme/AUDIT_REPORT.md`.
2. Create `.ufme/DEPLOYMENT.md` (build output, deploy target, environment variables).
3. Final quality-check via `scripts/quality-check.sh`.
4. Mark `.ufme/TASKS.md` (T-20) COMPLETE and `.ufme/AGENT_STATE.md` as delivered.
5. Create `.ufme/SKILL_VALIDATION.md` documenting files created, environment findings,
   browser status, Selenium Manager status, agent discovery, delegation map, permission
   validation, validation errors/resolutions, Arch limitations.

## Output
- `.ufme/DEPLOYMENT.md`
- `.ufme/SKILL_VALIDATION.md`
- `.ufme/TASKS.md` (all COMPLETE)
- Production-ready website

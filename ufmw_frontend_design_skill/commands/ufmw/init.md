# ufmw init

Initialize the current project for reference-driven website engineering.

Creates:
  - .ufme/REFERENCES.md — catalog of reference URLs
  - .ufme/ELEMENT_MAP.md — element-to-location mapping
  - .ufme/DESIGN_ADAPTATIONS.md — design adaptation rules

Usage:
  ufmw init

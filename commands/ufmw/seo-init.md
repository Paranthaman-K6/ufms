# ufmw seo init

Initialize SEO project memory for the current project.

Creates:
  - .ufme/SEO_SPEC.md — SEO project specification
  - .ufme/SEO_CRAWL.md — crawl results summary
  - .ufme/SEO_AUDIT.md — SEO audit findings
  - .ufme/SEO_PLAN.md — prioritized improvement plan
  - .ufme/SEO_RESULTS.md — verification results
  - .ufme/SEO_METRICS.md — SEO metrics over time

Usage:
  ufmw seo init

# ufmw seo report <url>

Generate a comprehensive SEO audit report combining crawl, analysis,
plan, and verification results.

Usage:
  ufmw seo report <url>

Example:
  ufmw seo report https://example.com

Output:
  - .ufme/SEO_AUDIT_REPORT.md — final audit report
  - .ufme/evidence/seo-report.json — machine-readable report

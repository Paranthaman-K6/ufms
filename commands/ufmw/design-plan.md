# ufmw design plan

Generate a prioritized implementation plan that matches each reference
element to a destination in the target project.

Usage:
  ufmw design plan

Output:
  - .ufme/evidence/reference-match.json — machine-readable match plan
  - .ufme/DESIGN_ADAPTATIONS.md — how each element is adapted

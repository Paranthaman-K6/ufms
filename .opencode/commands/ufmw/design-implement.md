# ufmw design implement

Implement adapted reference elements in the target project's source code,
adapting them to the project's existing design system.

Usage:
  ufmw design implement

Output:
  - .ufme/REFERENCE_IMPLEMENTATION.md — component code (HTML/CSS)
  - .ufme/evidence/reference-adapt.json — machine-readable adaptation
